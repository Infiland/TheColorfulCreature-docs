Xcode 26.6 (17F113) is installed at `/Applications/Xcode-26.6.app`. Use `DEVELOPER_DIR` per build; the system default still points to Xcode 27. iOS extensions were rebuilt with Xcode 26.6 for iOS 15+. The iOS exporter removes the legacy `-ld64` flag: it triggered a linker assertion under Xcode 26.6 and a missing-library error under Xcode 27.

```sh
export DEVELOPER_DIR=/Applications/Xcode-26.6.app/Contents/Developer
python3 tools/build.py Check --output ~/Library/Caches/TCCPort/check --clean --native-diagnostic --self-check
python3 tools/build.py Steam --output ~/Library/Caches/TCCPort/steam --native-diagnostic
python3 tools/build.py MacAppStore --output ~/Library/Caches/TCCPort/mac-app-store-xcode26 --clean --native-diagnostic
python3 tools/build.py iOS --output ~/Library/Caches/TCCPort/ios-xcode26 --clean
python3 tools/build.py Android --output ~/Library/Caches/TCCPort/android --clean
```

`Apple` is the unsigned diagnostic configuration. `MacAppStore` adds the store/sandbox options. `iOS` and `MacAppStore` inherit Apple services and exclude Steam; `Android` inherits Mobile and excludes Steam. Steam retains the full desktop feature set. The wrapper records evidence beside each build. `TCC_GM_USER`, `TCC_GM_RUNTIME`, `TCC_GM_PREFABS`, and `TCC_STEAM_SDK` allow machine-specific paths. The default SDK path is `../../sdk`, relative to the project.

The asset compiler crashed in room-property parsing before source compilation with default host settings. Disabling .NET hardware intrinsics together with single-worker compilation got past that failure; the two changes have not been isolated.

- Centralized GUI-space touch sampling before gameplay. Native press edges and per-finger ownership preserve rapid re-taps, simultaneous movement/actions, and an additional finger tapping an already-held action. Each contact selects one nearest control, including overlapping custom layouts.
- Added modest hit padding and hold tolerance for thumb drift. Sliding between movement buttons stays immediate. Drawing now uses the same GUI coordinates as hit testing, without repositioning controls again during Draw.
- Pause uses the shared multitouch path. Interruptions and dialogs clear ownership. Spiral pickups consume the player's sampled action and ignore collisions while paused instead of dereferencing destroyed controls. Jump physics and coyote timing are unchanged.
- Added deterministic contact-frame regression checks to the existing isolated `iOSCheck` runtime route. Both iPhone and iPad iOS 18.5 Simulators reached `TCC_TOUCH_INPUT_PASS`, `TCC_TOUCH_LAYOUT_PASS`, and `TCC_MOBILE_SMOKE_PASS`. Checks exercise simultaneous movement/jump, an airborne double jump, re-taps, overlapping fingers/controls, drift, release, direction changes, interruption/background/pause gates, and spiral interactions.
- The native macOS `Check --native-diagnostic --self-check` build passed, and `python3 tools/check_port.py` passed. Logs and simulator build: `~/Library/Caches/TCCPort/mobile-controls-20260926/`; macOS evidence: `~/Library/Caches/TCCPort/mobile-controls-check-20260926/`.
- Live simulator layouts and iPhone held movement were visually verified. Scripted contact-frame assertions are not physical multitouch tests; synthetic instantaneous click attempts did not independently establish quick-tap behavior. No physical-device or Android runtime touch test was performed for this change. No store build was uploaded.
